## ✨ About the Project

**DIPSTORE** is a fashion e-commerce mobile application developed using Flutter. The project focuses on creating a clean shopping interface, convenient navigation, and user authentication.

The application brings together essential shopping features in one place, with a focus on usability, visual design, and a smooth user experience.

## 🚀 Features

- 🛍️ **Fashion Shopping Interface** — Browse products through a dedicated shopping interface.
- 🔐 **User Authentication** — Sign in and register using email and password.
- 🔑 **Google Sign-In** — Google authentication integration.
- 📩 **Forgot Password** — Request a password reset email.
- ❤️ **Favourites / Wishlist** — Access your favourite products.
- 🔎 **Search** — Find products through the search screen.
- 🔔 **Notifications** — View notifications and unread notification counts.
- 👤 **Profile Screen** — Access the user's profile.
- 🧭 **Bottom Navigation** — Navigate between the main app sections.

## ⚙️ Getting Started

### Prerequisites

Before running the project, install:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart)
- [Android Studio](https://developer.android.com/studio) or [VS Code](https://code.visualstudio.com/)
- A configured Firebase project

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/DIPSTORE.git
```

**2. Open the project directory**

```bash
cd DIPSTORE
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Configure Firebase**

Use your own Firebase project configuration for the supported platforms. Do not commit private credentials or API secrets.

**5. Run the application**

```bash
flutter run
```
